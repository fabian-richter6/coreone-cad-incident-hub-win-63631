## About CoreOne CAD

CoreOne CAD is built for FiveM-driven dispatch environments that need a browser-accessible way to manage incidents and coordinate response activity. It combines CAD-style dispatch controls with a modern web interface so operators can follow active situations without relying on a heavy local client.

This release focuses on the day-to-day workflow of a dispatcher: viewing incidents as they come in, tracking which units are assigned, and keeping decisions tied to a map-first layout. Because it runs as a browser app, it can fit into existing setups where quick access and low-friction operation matter.
